# Workflow Observation Playbook

## Objective

Capture how work actually happens, including handoffs, waiting, interruptions, exceptions, rework, informal decisions, and hidden tools.

## Observation protocol

1. Select representative normal, difficult, failed, and urgent cases.
2. Obtain appropriate permission and protect sensitive information.
3. Observe the case from trigger to final output where possible.
4. Record facts before interpreting them.
5. Ask the participant to explain decisions after the action when interruption would distort the work.
6. Capture system evidence, timestamps, artifacts, and screenshots only when authorized.

## For each activity record

- timestamp
- actor and role
- trigger
- input and format
- application, file, channel, or device
- action performed
- rule or judgment applied
- output
- handling time
- waiting time
- handoff recipient
- failure or exception
- workaround
- evidence reference
- observer confidence

## Exception prompts

- What happens if this input is missing?
- What if the value conflicts with another system?
- What if the usual approver is unavailable?
- What if the system is down?
- What if this is urgent or high value?
- What if the customer disputes the result?
- What if the file format changes?
- What if the same request arrives twice?
- What if policy and business urgency conflict?

## Hidden-work checklist

Look for:

- copying between applications
- personal spreadsheets
- browser bookmarks and saved searches
- email templates
- private messaging channels
- manual quality checks
- repeated status inquiries
- unofficial approval chains
- locally stored files
- memorized mappings or thresholds
- end-of-day reconciliation
- work performed outside the official system

## Outputs

- observation log
- exception register
- workaround inventory
- workflow variance report
- tacit-knowledge inventory
- evidence-linked draft workflow

## Quality checks

- Were multiple cases observed?
- Were both handling time and waiting time captured?
- Were exceptions observed or only described?
- Were hidden tools and informal communications recorded?
- Were privacy and consent requirements followed?
