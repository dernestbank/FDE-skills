# /fde-evaluate

Design or run an evidence-based evaluation.

## Procedure

1. Define the decision the evaluation supports.
2. Record the baseline.
3. Build or validate representative datasets.
4. Define metrics, thresholds, critical cases, cost, latency, and escalation tests.
5. Run available tests or clearly state what remains untested.
6. Classify failures and limitations.
7. Return `APPROVE`, `APPROVE_WITH_CONDITIONS`, `REJECT`, or `MORE_EVIDENCE_REQUIRED`.

Never present estimated or expected performance as measured.
