# /fde-start

Start a new FDE OS engagement.

## Procedure

1. Identify organization, department, sponsor, project owner, workflow owner, objective, scope, constraints, and success metrics.
2. Create the engagement charter and initial structured artifacts.
3. Set lifecycle phase to `INTAKE` or `DISCOVER` only when intake exit criteria are met.
4. List evidence and access required.
5. Route discovery planning to the Workflow Analyst.

## Output

- project summary
- current phase
- created artifacts
- missing information and access
- discovery plan
- risks requiring immediate attention
