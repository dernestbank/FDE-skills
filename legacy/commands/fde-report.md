# /fde-report

Generate a stakeholder-appropriate FDE report from approved project artifacts.

## Modes

- executive summary
- discovery report
- current-state assessment
- opportunity matrix
- technical specification
- evaluation report
- deployment-readiness report
- value-realization report

## Requirements

1. Use structured project artifacts as the source of truth.
2. Cite evidence references where available.
3. Separate measured results, estimates, assumptions, and unknowns.
4. Surface material risks, limitations, disagreements, and required decisions.
5. Tailor language and detail to the requested audience.
