# /fde-map

Create or update the evidence-linked current-state workflow.

## Procedure

1. Validate that discovery and observation evidence exists.
2. Build steps, actors, systems, inputs, outputs, decisions, controls, times, failures, exceptions, and evidence links.
3. Mark confidence and disputed findings.
4. Generate the exception register, bottleneck analysis, system map, and data-flow map.
5. Run workflow validation.

Do not mark the map complete when material steps lack owners, evidence, or failure behavior.
