# /fde-design

Design the future-state workflow and system architecture for an approved opportunity.

## Procedure

1. Confirm the opportunity recommendation and evidence.
2. Simplify the workflow before automating it.
3. Classify every future-state step by execution type.
4. Define AI components, deterministic validation, tools, permissions, schemas, confidence, failure handling, and human control.
5. Produce architecture, tool contracts, human-control matrix, security design, evaluation plan, and deployment outline.
6. Request independent Security and Evaluation reviews.

Do not grant autonomy beyond current evidence.
