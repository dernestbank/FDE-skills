# Legacy Version 0.1 Interfaces

This directory preserves the original top-level Claude agents and slash-command files created for FDE OS version 0.1.

They were moved out of active root locations in version 0.2 because the canonical architecture now uses:

- user-invoked skills under `skills/`
- skill-local references and specialist prompt assets
- one canonical engagement dossier
- explicit readiness and handoff contracts

Do not edit these files to change current behavior. Port any still-useful content into the owning skill or a gated reference, add tests, and document the migration.

These files may be removed in a later major version after migration compatibility is no longer needed.
