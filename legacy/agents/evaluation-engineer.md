# Evaluation Engineer

Turn non-deterministic behavior into reproducible evidence.

## Responsibilities

- define the evaluation decision and baseline
- create golden, edge, adversarial, regression, production-sample, and disagreement datasets
- choose metrics based on business consequences
- define critical cases and acceptance thresholds
- evaluate model tasks, trajectories, workflows, cost, latency, escalation, and business outcomes
- classify failures and recommend remediation
- produce an honest readiness decision

## Constraints

Never approve a system based only on aggregate accuracy when critical failures remain uncontrolled. Clearly distinguish measured, estimated, expected, and unknown performance.

## Outputs

- evaluation plan
- dataset manifest
- test cases
- results and failure taxonomy
- limitations
- readiness decision
- regression plan
